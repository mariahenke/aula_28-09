## Pré-requisitos do React

Para utilizar o React 18, é recomendado usar uma versão do Node.js que seja compatível com os requisitos mínimos do React e suas dependências. De acordo com as práticas atuais, o Node.js versão 14.0.0 ou superior é necessário para garantir o funcionamento adequado do React 18 e suas ferramentas associadas, como o npm ou yarn.

Para realizar a instalação do React Router, uma biblioteca padrão para lidar com roteamento em aplicações React, utiliza-se o gerenciador de pacotes Node Package Manager.

## Comando CLI — Criação do Projeto

Para a criação do diretório do projeto, utiliza-se o comando:

`MKDIR projeto`

Para acessar o diretório criado, utiliza-se o comando:

`CD projeto`

Projeto criado com sucesso!

## Instalação de Dependências e Execução da Aplicação

Para inicializar o NPM no projeto, utiliza-se o comando:

`NPM init -y`

Para instalar a dependência do React Router, utiliza-se o comando:

`npm install react-router-dom`

Para criar a aplicação React com o template Vite, utiliza-se o comando:

`npm create vite@latest . -- --template react`

Para executar a aplicação de maneira regular, utiliza-se o comando:

`npm run start`

Para executar a aplicação em modo de desenvolvimento com nodemon, utiliza-se o comando:

`npm run dev`

## package.json do Projeto

O package.json é um arquivo de configuração de projetos Node.js que armazena dependências, scripts e metadados do projeto. Ele serve como um manifesto do projeto, listando todos os pacotes necessários para o funcionamento do projeto e permitindo que o npm instale dependências e execute scripts.

O package.json é essencial para a organização e o gerenciamento de projetos JavaScript, facilitando o compartilhamento e a colaboração entre desenvolvedores.
